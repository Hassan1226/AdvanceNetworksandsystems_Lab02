# Lab 02 – Fat-Tree Topology and Routing

## Overview
Implemented configurable fat-tree topologies and routing algorithms to explore network scalability and performance in Software-Defined Networking (SDN).

## Features
- **Fat-Tree Topology:** Generated different topology sizes and validated node degrees and link counts.
- **Shortest-Path Routing:** Configured flow rules, port discovery, and ARP handling to ensure server connectivity.
- **Two-Level Routing:** Implemented routing based on the fat-tree architecture.
- **Performance Evaluation:** Conducted experiments and generated plots to compare routing performance.
- **ECMP Routing (Bonus):** Implemented Equal-Cost Multi-Path routing to distribute traffic across multiple paths and evaluate load balancing performance.

## Technologies
- Python
- Mininet
- OpenFlow / SDN
- Network Performance Analysis
